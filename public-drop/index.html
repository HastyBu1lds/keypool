Solana wallets · no seed phrase

One secret, not two.

A normal wallet gives you a private key and a seed phrase. The phrase can unlock everything, and people leave it in notes, photos and cloud backups. Here each wallet is only a private key. There is no phrase to steal, lose or photograph.

Store it like Satoshi did. Random keys in one backup file, the way Bitcoin's first wallets worked.

A Keypool wallet

One secret: the private key.

Each key is random and separate. There is no master phrase, and one leaked key cannot open the others.

An honest note. Your backup file holds copies of your keys, so whoever gets the file gets the wallets inside it. Guard it like the keys themselves: lock it with a passphrase, or save a wallet on its own with “Save only this wallet” so a leaked file exposes one wallet, not all of them.

The Satoshi way

Bitcoin's first software, written by Satoshi Nakamoto, worked like this. It made random keys, kept them in one wallet file, and you backed up the file. There were no recovery words at all. Keypool does the same for Solana.

  1. 2009Bitcoin's first wallets keep random private keys in a file called wallet.dat, with a spare supply of keys called the keypool. That is where our name comes from.
  2. 2013Seed phrases (12 or 24 words) arrive, so one phrase can rebuild every key. Handy, but it is one master secret.
  3. NowKeypool brings the original way to Solana: one random key per wallet, saved in a backup file that you guard.

Questions

What do these words mean?
Wallet address
Where people send coins. Safe to share.
Private key
The secret that lets you spend. Never share it.
Backup file
A list of your private keys. Lose every copy and the coins are gone. Nobody can reset it.
Passphrase
An optional password that locks the file. If you forget it, the file cannot be opened.
Is this really how Satoshi's wallets worked?

In spirit, yes. The first Bitcoin software kept random private keys in a wallet file and had no seed phrase, so the file was the backup. Seed phrases only came later, around 2013.

Two honest differences: Keypool makes Solana keys, not Bitcoin ones, and it saves a file in its own format, not Bitcoin's wallet.dat.

What is the catch?

Without a seed phrase, new wallets are not covered by your old backup. Save a new backup file every time you make or add wallets.

The backup file is also a single file holding your keys. Anyone who gets it can spend what is in those wallets, so lock it with a passphrase, keep copies somewhere private, or save wallets one at a time with “Save only this wallet”. Keypool is not audited, so try a small amount first.

Can I trust this page?

The page is set up so it cannot make any network request, so it has no way to send a key anywhere. You can check this in your browser's developer tools. For larger amounts, save this page, disconnect from the internet, and open it from your own disk.

The source code is public, so you can read how the keys are made: github.com/HastyBu1lds/keypool. The full explanation is in the docs.

Printing a paper wallet puts private keys on paper and in the printer's queue. Use a printer you trust.

How do I use a wallet in Phantom or Solflare?

In the wallet app, choose “Import private key” (not “recovery phrase”) and paste the private key. Phantom, Solflare and Backpack all work this way.
