WHY NO SEED PHRASE?

A normal wallet gives you two secrets: a private key and a seed phrase (12 or 24 words). The seed phrase is a master password. Anyone who sees it can rebuild every wallet made from it, and people leave it in notes, photos and cloud backups.

Here there is only one secret per wallet: its private key. Each key is random and separate, so there is no master phrase, and one leaked key cannot open the others.

HOW TO USE IT

  1. Press Make wallets.
  2. Press Save backup file. This file holds your private keys. It is your only backup.
  3. Copy the file to two other places (a USB stick, another computer).
  4. Send a small amount to a wallet address first, then send it back out to check it works.

WORDS EXPLAINED

  • Wallet address: where people send coins. Safe to share.
  • Private key: the secret that lets you spend. Never share it.
  • Backup file: a list of your private keys. Lose every copy and the coins are gone. Nobody can reset it.
  • Passphrase: an optional password that locks the file. If you forget it, the file cannot be opened.

THE TRADE-OFF

Without a seed phrase, new wallets are not covered by your old backup. Save a new backup file every time you make or add wallets.

CAN I TRUST THIS PAGE?

The page is set up so it cannot make any network request, so it has no way to send a key anywhere. You can check this in your browser's developer tools. For larger amounts, save this page, disconnect from the internet, and open it from your own disk.

Printing a paper wallet puts private keys on paper and in the printer's queue. Use a printer you trust.

To use a wallet in Phantom, Solflare or Backpack, choose "Import private key" (not "recovery phrase") and paste the private key.
