Keypool: logo concepts, round 2

Eight new ideas, G to N. The first six are still on the first page. Same rule: pick one and the whole site is built from it.

G Lone key

keypool
app icon / tab / favicon

One plain, well-drawn key at 45 degrees. No tricks: the single key is the whole brand.

Site built around it: Night blue with a pale sky tint. Big photographic key, crisp and calm.

H Block key

keypool
app icon / tab / favicon

A key built from square blocks, like a bitmap. Plain, digital, and it holds up at tiny sizes.

Site built around it: Loud sun-yellow with black. Chunky grid layout, big flat blocks, friendly type.

I Drop

keypool
app icon / tab / favicon

A water drop with a keyhole in it: a pool, and a secret held inside.

Site built around it: Deep sea-blue with white. Soft, rounded shapes and slow ripples on scroll.

J Monoline key

keypool
app icon / tab / favicon

A key drawn with one even line and round ends, and a single dot. Light, friendly, easy to animate.

Site built around it: Lavender and indigo with one pink dot. Rounded, airy, line-drawn illustrations.

K k with a ring

keypool
app icon / tab / favicon

A lowercase k whose tall stem ends in a key ring. Friendly, easy to recognise as a letter.

Site built around it: Terracotta and white. Warm, human, rounded type, hand-drawn touches.

L Dial

keypool
app icon / tab / favicon

A safe dial with one marked tick. The one number that opens it is yours alone.

Site built around it: Brushed grey panel, black dial, one orange mark. Real knobs, bevels and LED lights.

M Key and ghost

keypool
app icon / tab / favicon

A solid key above a dashed ghost of itself. The second secret is gone, and only one is left.

Site built around it: Black and white with one red-orange dot. Stark, big type, lots of empty space.

N Bracket one

keypool
app icon / tab / favicon

The numeral 1 held in square brackets, like one item in a list. Technical, exact, quiet.

Site built around it: White page with black ink and one electric violet. Code-like grid, tidy and precise.
